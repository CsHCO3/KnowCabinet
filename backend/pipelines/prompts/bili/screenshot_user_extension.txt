
# 截图标记规则（代码解析这些标记，不要修改格式）
1. 在"操作步骤"章节，对关键操作标注 `[SHOTLINE:行号|该步画面简述]`
2. 在"核心内容"章节，对架构图、对比结果、性能数据等关键画面标注 `[SHOTLINE:行号|画面简述]`
3. 格式必须是 `[SHOTLINE:行号]` 或 `[SHOTLINE:行号|理由]`，不要使用其他格式
4. 标注要克制：整个报告不超过 8 处，只在真正值得截图的画面标注
5. 每个行号只用一次

## 好的标注示例
[SHOTLINE:42|pip install 命令执行结果]
[SHOTLINE:156|AutoGen架构图：三智能体通信拓扑]

## 不好的标注（不要这样写）
[SHOTLINE:1]          ← 第一行就标，通常是废话
[SHOTLINE:99|这里很重要]  ← 理由太模糊，不知道截什么
