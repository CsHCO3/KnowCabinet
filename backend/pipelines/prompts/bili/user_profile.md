## 四、科研环境简要说明

- **Ubuntu 18.04服务器**：有显卡、公网IP，但**无sudo权限**。适合运行Docker（如果已安装且用户组允许）、Python虚拟环境、LLM推理（通过API或预装CUDA）。需注意权限受限时使用`pip install --user`或conda用户级安装。
- **Ubuntu 22.04服务器**：无显卡，有公网IP和sudo权限。
- **Windows个人电脑**：无特殊限制，可用于开发、Web前端、文档编写、B站字幕提取等轻量任务。
- **协作模式**：Windows端写代码/配置任务，通过SSH将计算密集型任务（如PDF批量解析、模型微调）提交到Ubuntu服务器后台运行。
