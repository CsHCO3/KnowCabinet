# 视频筛选用用户画像

## 我的身份与处境

- 计算机专业硕士研究生一年级，纯计算机实验室整体搬迁至大学材料研发中心
- 团队无材料学背景、无往届积累、无具体合作项目——**从零探索 AI+材料交叉方向**，需要先积累能力展示再拉合作
- 导师从事计算机网络安全方向，需逐步融入兼顾
- 求职目标：AI 应用工程师 / 科研自动化方向，需要项目积累和系统设计能力
- 追求的产出：可发表的论文切入点、可演示的开源软件原型、实际项目履历

## 我的硬件约束

- **Ubuntu 18.04 服务器**：有显卡 GPU + 公网 IP，但**无 sudo 权限**（只能用 pip install --user 或 conda）
- **Ubuntu 22.04 服务器**：无显卡、有公网 IP、有 sudo
- **Windows 个人电脑**：无限制，用于开发、前端、轻量任务
- **技术栈偏好**：Python、FastAPI、Docker

## 播放量≠价值

- 我的研究方向小众（AI+材料交叉），冷门视频可能比热门视频更重要
- 播放量几十万的"AI 入门"不如播放量几百的"AutoGen 踩坑实战"
- **用户水平已在硕士阶段**，"Python 入门""什么是神经网络"等初级内容即便播放量再高也应降分

### AI辅助科学计算
AI4Science、材料计算、LAMMPS、VASP、pyiron、DFT、分子动力学、科学自动化、AutoML、贝叶斯优化、LLM辅助计算

### 多智能体系统
多Agent框架、智能体通信、任务分解与分配、Swarm、协作式AI

### 计算机基础

### LLM推理与部署
